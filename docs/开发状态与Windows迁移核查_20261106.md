## 本轮 Windows 实测

环境：Windows PowerShell；本机 `C:\Users\Administrator\.jdks\jbr-21.0.11`，Maven Wrapper 3.9.11，仓库 `.tools/m2` 离线依赖。开始检查时JAVA_HOME未设置，PATH中未找到java/mvn/psql/docker；找到了本机JDK21后，只为测试进程设置变量，没有修改系统环境。

命令：

```powershell
$env:JAVA_HOME = 'C:/Users/Administrator/.jdks/jbr-21.0.11'
$env:MAVEN_USER_HOME = Join-Path $PWD '.tools/maven-home'
.\mvnw.cmd -o '-Dmaven.repo.local=.tools/m2' test
```

结果：**69项，2失败、3错误、0跳过，BUILD FAILURE**。本次日志：[windows-review-test.log](../target/windows-review-test.log)（target为本机临时产物，不随Git提交）。

| 测试 | 结果/原因 |
|---|---|
| TestSchemaCleanerTest.registrationIsDeletedBeforeUserAndSchoolAndReceiptIsNotImplied | 1失败；预期遗漏V031平台子表，即R7 |
| CliOperatorDirectoryTest.forgedUserNameDoesNotChangeProtectedReviewer | 1错误；无法确认当前操作系统用户 |
| CliOperatorStartupTest.startupKeepsReviewerWhenUserNameAndUserEnvAreForged | 1失败；预期退出0，实际退出2 |
| CliOperatorStartupTest.startupRejectsOperatorSystemPropertyOverride / startupRejectsOperatorEnvironmentOverride | 2错误；无法确认当前操作系统用户 |
| 其余64项 | 通过；不包括由Failsafe执行的*IT |

新增迁移问题W1：CliOperatorDirectory.currentOsUser/effectiveUid依赖`/proc/self/status`和`com.sun.security.auth.module.UnixSystem`，因此Windows的可信CLI身份路径不可用。不要通过移除防伪造测试或信任可覆盖的环境变量绕过。

环境缺口W2：`scripts/run-pg-tests.sh`所需的Linux JDK/Maven/PostgreSQL不在当前`.tools`中；本机未发现可直接使用的PostgreSQL测试工具。没有执行verify，不声称数据库迁移/锁/路由测试通过。

旧审查中“69单元1失败、240集成1错误”是Linux历史结果，与本次Windows的“69单元2失败3错误”是两次不同运行。历史ChatFixP13IT通知外键清理不稳定现象本轮未重现也未关闭。
