## 改动摘要

1. **S01**：`chat_sync_cursor` 从“服务端消费位置”改为不可变边界；旧 token 重试仍返回同一批事件，扫描边界通过新 token 前进；V020 统一失效 V019 旧 token；定时批量清理过期 token。
2. **S02**：作品证据的正式交付、确认、独立验收统一绑定 `submission.agreement_version`；旧版本份额不分享新版本接任成果；独立验收自验判断只按当次版本。
3. **S03**：普通任务 `REVIEWED + PASSED` 按 `submitted_by` 形成整任务有效交付；普通独立验收单独分支；`sources` 与 `canReference` 共用证据 CTE。
4. **S05**：成绩交接只读当前 `plan_version`；同任务全部有效阻断确定性排序并编码进 sourceKey；已执行 blocked 与解除规则保留。
5. **S04/S06**：新增 `personnel_case_grant` 与 `PersonnelCaseAccessPolicy`；当前任课教师保留原权属，管理员 CLI 可授予接续教师单 case 资格；候选、创建、接受、待办、材料、收回共用策略；学生 membership 不再作为教师接续资格，只作为回避条件；case 写入的幂等回放重新核权。
6. **D01**：仅保留唯一任课教师，不新增第二条 active 关系；授权不自动接任，接受后才成为 assignee。

## 兼容变化

- V019 及更早签发的聊天同步 token 在 V020 升级时全部失效，客户端收到 409 `CHAT_SYNC_EXPIRED` 后重建基线；消息、变更、已读、作品、幂等回执不删除。
- 作品来源新增普通任务证据；正式与普通计数分开去重后合并。仅有历史旧版本份额、未参与该次有效交付的用户不再获得证据。
- 成绩交接只在当前方案版本及 `task.handover_blocked` 成立时阻断。
- 人员事项新增 case 级教师授权 CLI；未授权教师即使有全局 TEACHER 角色也不能读取/办理该 case；管理员不获得 App 案情正文读取权。
