# 分步开发与验收

## 1. 执行原则

阶段按依赖顺序执行，不按接口编号机械平铺。一个阶段可以交给一个模型完成；下一模型须读上一阶段的迁移和验证记录。各阶段都使用真实数据库。下面路径是未来代码交付要求，本次文档交付没有创建这些实现文件。

每阶段通用交付：

1. 在`src/main/resources/db/migration`添加不可改历史的Flyway SQL，列清表/FK/CHECK/唯一索引。
2. 在目标模块实现typed DTO、Policy、领域规则、Repository和ApplicationService。
3. 先为关键状态/并发行为建立测试，再接Controller；简单字段映射不写机械重复测试。
4. 从原契约复制合法示例为请求fixture，按01纠正冲突；所有用户/资源ID从演示数据或此前响应获取，不写死revision。
5. 完成接口成功、失败与数据库断言；并发用两个真实连接和屏障控制时序，不用sleep假定先后。
6. 更新覆盖清单中状态为已实现/后端验证通过/前端联调通过之一，附测试名；不得一步把所有接口标完成。
7. 输出变更文件、运行命令与真实结果、遗留问题、下一阶段依赖。不把未运行的命令写成通过。

## 2. 阶段计划

### P00 工程和契约基础

前置：01确认规则、原始契约及环境条件。

开发：初始化Java21/Boot3.5/Maven工程；锁定版本；提供local/test/demo配置；统一信封、异常处理、未知字段/类型拒绝、UTF-16限制、Instant输出、ID/Decimal校验。增加RequestId，日志不记录正文秘密。实现Clock和可控测试时间。连接PG与Flyway并提供最小健康检查。实现错误业务码枚举，不用字符串散落。

产物：pom.xml、mvnw、应用启动类、common/api/validation/clock、V001基础迁移、.env.example（无真实秘密）。

验证：空库迁移启动；JSON错误400，未知字段422，错误类型422；创建成功也200；404/401均JSON；小数点数保持字符串；中文/代理对长度边界；响应过大拒绝。不要先加281个占位路由。

### P01 账号、管理导入基础与幂等

前置P00。先建用户、会话、访问token、幂等、审计、限流表。CLI导入虚构用户；实现AUTH全部8接口与统一认证过滤器。实现幂等事务模板、规范摘要、try事务锁、回放核权。加当前用户Policy基座；明确public帮助路径白名单。

产物：identity、common/security/idempotency、admin基础CLI、登录演示数据。

验证：密码哈希与token摘要数据库无明文；access到期、refresh固定到期、注销全部旧access、停用即时生效；登录5次封禁；并发同键一次效果、异正文409、落库后丢回包重试返回相同业务ID；数据库中途异常全部回滚。

### P02 课程字典、可信名单与作业

前置P01。按03建立school/term/period/verified_course/enrollment/square/assignment。CLI导入顺序固定：学校→学期节次→用户→真实课程→选课事实。实现规范课表签名、匹配token、广场创建、字典读取、作业创建确认。

先实现COURSE-01～12；创建后所有资源关系由服务器确定。导入dry-run列出未知外键、重复学号、时区错误，apply整批或明确按文件事务，不能悄悄略过坏行。

验证：同名不同真实班不混同、同一规范输入并发不重复、学生作业未确认不能正式评分、越校/越学期拒绝。

### P02B 教师、授权与课程码

前置P02。实现TEACH全10接口；CLI认领审核；再实现COURSE-13～22。补真实受理授权查询，码管理与审批能力独立。课程转交撤销旧码，授予/撤销刷新authorization_epoch。

验证：无审阅人503且不建申请，可信名单确认与普通申请分流，自审拒绝，过期grant请求即时失效；旧教师与新教师并发写符合权属。

### P03 项目、申请与邀请

前置P02B。实现TEAM的核心创建/读取/申请/邀请/码与本人项目。先实现assignment_team_slot唯一约束、容量锁、席位预留，再接HTTP；不要先用count后insert代替事务。TODO总览先提供已完成模块的真实投影，后续逐步扩充，不宣称完整完成。

验证：原文IT04；同一作业两团队邀请并发只成功一次；成功后其他预留释放；预留满不能继续邀请；QUICK/DETAILED分支；归档资格仍占用。

### P04 岗位协商与项目设置

前置P03。实现ROLE全21接口，完善TEAM-14/24。实现岗位id/clientKey同传兼容、新增clientKey、删除引用保护、快速升级、多人来源快照与最后确认事务。

验证：所有相关本人明确确认；对任一参与者撤权/离组/改岗后的原方案不可应用；新成员加入不能让旧岗位计划覆盖其位置；岗位变更不改任务责任。

### P05F 文件基础

前置P01；项目用途依赖P03，事项/工单用途先实现策略接口，P07/P15接入真实资源。实现FILE-01～04及URL字节处理端点；文件收发流式、私有目录、token和校验、孤立恢复任务。不得给未实现的事项策略返回true占位。

验证：实际PNG/PDF/TXT/DOCX样本；扩展名与真实签名不符、字节超额、截断上传、READY前引用、过期token、重复覆盖、权限撤销后旧URL。验证DB和文件落盘不一致的恢复路径。

### P05 任务、看板和依赖

前置P04。TASK全10接口，首版普通任务；正式分支需P06完成才标接口全通过。建阶段、任务标准、依赖图、owner条件更新；认领和开始分离。

验证：IT05，200任务上限，BEFORE_START/BEFORE_SUBMIT，环、跨项目依赖、阶段改动不改状态。没有取消任务接口。

### P06 正式分工、提交、验收

前置P05/P05F。按顺序实现约定创建/读取/本人回应→验收邀请→本人草稿→提交→验收/自检/撤回→本人贡献确认→未验收项调整/意见→交接重签接口（后续接P07）。完成DELIVERY21接口及TASK正式分支。

必须先写份额守恒和验收标准匹配函数；验收/撤回一个事务竞争。文件引用与提交快照同时提交。正式任务必须自己确认，组长发布不自动签到。

验证：IT06/07；多个贡献者共同项、部分通过重交、原标准不可改、组长自检条件、待验收不能调份额、草稿恢复冲突、验收过但未确认不计分。P07前重签对无有效交接必须拒绝，不能假成功。

### P07 人员治理与交接

前置P06/P02B。按事项/补资料→接续处理→退出转组→交接方案/本人回应→最终执行→移出表决顺序完成GOV41接口。增加48h/72h时间任务和投票资格冻结。完成P06的重签集成。

验证：所有任务接任加组长LEADER项单独接受（兼容空数组别名）后才执行；目标预留过期/源任务变更/待验收阻止执行；成员资格原子移动；正式旧贡献不转移，未完份额新确认；人员事项隐私投影；QUALIFICATION_REVIEW取消重发。

### P08 广场合并

前置P07。MERGE7接口，核验真实班级与教师；两侧选民/票分别存；事实核对所有作业keepSeparate；迁移关系去重，留原资源追溯。

验证：两侧分别过半、一侧未通过拒绝；独立作业/成绩/项目ID不变；旧加入码失效；助理旧授权不扩权；旧游标失效；教师不因此读项目聊天。

### P09 教学与正式成绩

前置P06/P07。先实现账本投影与gaps→规则预览确认→教学更正→结算→教师草稿→发布预览/发布→复核→文字评价和展示授权，覆盖GRADE24接口。

验证：使用确定数值断言，例责任30.00、验收20.00，B=67；w=0.60、Q=80、Δ=2，G=74。另测0分母、HALF_UP边界、上下界clamp、未签/待确认阻塞、到期未交0验收、迟交后旧来源失效；批次任何一人变化整体回滚；同分新依据允许修订；复核必须关联新快照才结案。

### P10 报告与归档

### P11 画像、作品、互评与AI参考

## 4. 交给模型的阶段任务模板

```
目标：实现Pxx，完整覆盖该阶段接口。先阅读docs/backend/README.md、01、02、03、04对应模块、05阶段与07原接口链接。
约束：使用既定栈与现有结构；不改已确认契约；不用假成功/内存数据代替持久化；不提前标前端兼容。
步骤：检查现有代码与迁移→列本阶段差距→实现迁移/规则/事务→接DTO/Controller→执行关键验证→更新覆盖证据。
结果：列文件与设计对应关系，给实际运行命令/结果，报告剩余问题。若遇未定义业务，给具体输入和分歧，停止该分支并继续独立工作。
```

## 5. 工程验证命令约定

未来工程统一提供`./mvnw test`运行单元/契约测试，`./mvnw verify`运行集成测试；测试profile隔离数据库与文件目录。部署构建在开发机/CI完成，不在2GB服务器上同时跑编译和全套数据库测试。接口覆盖脚本读取Spring映射与07清单，排除健康检查及文件字节端点，必须精确匹配281方法/路径。

每次测试报告保存执行时间、commit（若有）、版本、场景、请求ID、断言与结果；敏感token/密码脱敏。仅文档结构验证不能记为业务测试通过。
