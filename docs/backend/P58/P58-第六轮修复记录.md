## 迁移

`V028__agreement_renewal_reason_and_acceptance_revision.sql`：

- `agreement.renewal_reason varchar(500)`，可空。旧约定保持空，响应省略该字段。
- `acceptance.revision int NOT NULL DEFAULT 1`，并限制在 1～999999999。验收行没有更新语句。旧库升级用例在 V027 插入一条验收，升到最新后 revision 仍是 1，理由没有被改写。空库升级后该列存在且不可空，续约说明列可空。

新的计划 JSON 会带上分项 `dueAt` 和 `revision`。旧 JSON 没有这两项时仍能读取。
