## 优先级与边界

用户已确认的补充规则 > 原文具体接口业务规则 > 原文通用规则 > 自动展开的字段表/示例。不能仅因示例缺字段就省略响应必填字段。若同一优先级仍矛盾，记录具体接口、请求与后果，先讨论，禁止静默编造业务。

后端实现全部 281 个接口，不能用固定成功、假列表、仅内存数据替代业务。项目是课程演示，采用模块化单体；不增加微服务、Redis、消息中间件、云对象存储或管理网页。全部管理工作使用受控 CLI。管理员也不能直接通过普通 App 获取教师、组长或聊天读取权限。

每个接口必须具备 DTO、字段白名单、授权、持久化查询或事务、成功/错误投影和对应验证记录。状态转换必须通过真实业务操作验证。原文 IT01～IT20 全部执行；新增契约补充也要覆盖。代码完成与 Android 联调通过分开登记。
