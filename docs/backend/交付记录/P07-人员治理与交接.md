## 3. 实现要点

- 唯一成员不能退出或转组。一个成员同时只能有一件未结束的变更。组长离任必须指定另一名当前成员，并单独生成 `LEADER` 交接项。
- `itemIds=[]` 只表示接任组长确认这一项。接受任务项不会顺带接受组长项。两种形式落在同一条确认上。
- 执行前重验：教师已经 `ALLOW_HANDOVER`、方案版本一致、每项都被指定人接受、来源任务版本没变、没有待验收提交、已通过的贡献都已本人确认、转组目标没有过期或满员。
- 执行后原成员关系改为 `LEFT` 或 `REMOVED`，历史保留。受影响任务暂停开始和提交。重签把未完成份额交给接任人，已确认贡献不转移。新约定生效后才解除暂停。
- 移出表决先冻结除对象以外的当前成员，陈述 48 小时，投票 72 小时。严格过半且至少 2 张赞成才通过，并自动建立 `REMOVAL` 变更。选民资格变化则进入 `QUALIFICATION_REVIEW`，旧票作废。
- 人员核对只由当前教师执行。本组组员即使去操作也会回避。学生读取事项时看不到内部记录。
