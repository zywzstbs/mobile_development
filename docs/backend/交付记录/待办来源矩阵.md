## 已核查但不映射的源

|源|原因|处理|
|---|---|---|
|HELP 求助（`support_ticket` SUBMITTED/WAITING_USER）|P50 16 类没有 HELP/SUPPORT，且方案明确禁止新增 type 或强塞 TASK|列为具体待讨论项：源接口 HELP-*，预期用户=请求者/受理人，现有跳转=帮助中心；本轮不产生待办|
|SUPPORT 受理任务|同上；受理身份独立于项目/课程待办|同上|
|NOTIFICATION 未读|通知不是业务待办；清提示/标记已读不能完成待办|不进入聚合|

## 计数与去重

- `/me/todos` 与 `/me/dashboard` 复用同一 `TodoQueryService.todos(userId)` 一次计算结果，`actionCount/waitingCount` 由同一结果过滤，不用另一条 count SQL。
- 同一 `todoId` 只保留一条；同资源不同真实动作用不同 action 片段区分为不同 ID（如 AGREEMENT ACK / WAIT_ACK）。
- revision 取来源版本；updatedAt 取来源更新时间；不随读取次数变化。
- GET 不执行任何状态推进；终态/撤销/换版在下次读取自然消失。
