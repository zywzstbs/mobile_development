## 3. 实现要点

- 提出者必须是任一侧的当前学生，或两侧共同的当前教师。项目组长身份本身不能提出合并。
- 选民按提案建立时的当前学生冻结。同一人在两侧各有一张票。一侧赞成数的两倍大于该侧人数，才算该侧通过；两侧都通过才进入 `WAIT_TEACHER`。
- 事实核对只由两侧共同的当前教师执行。`CONFIRM` 必须把每一份来源作业恰好列一次，且 `keepSeparate` 为 true。`RETURN` 记为 `RETURNED`。
- 执行后作业和项目的编号不变，只把所属广场改到目标广场。来源广场记为 `MERGED`。来源加入码撤销。助理授权不复制到目标广场。两侧授权世代加一，旧的加入申请游标因此失效。
- 选民离开后提案进入 `QUALIFICATION_REVIEW`，旧票删除，广场可以重新提议。发起人或两侧共同教师可以取消仍未结束的提案；取消后也可以重新提议。已经执行、失败或取消的提案不能再取消。
