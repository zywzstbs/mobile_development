## 3. 数据库迁移 V005

- `project`：assignment/square/owner、QUICK/DETAILED、capacity、status、closing_cycle、authorization_epoch、招募设置、revision
- `project_stage`：默认阶段与顺序
- `role_slot`：岗位名称/职责/总人数/顺序
- `assignment_team_slot`：`(assignment_id,user_id)` 唯一，正式团队资格
- `membership`：project/user ACTIVE 部分唯一，LEADER/MEMBER、颜色/颜色版本
- `team_application`：同项目/同人 PENDING 唯一
- `team_invitation`：同项目/同人 PENDING 唯一、24h expires_at
- `seat_reservation`：同项目/同人 ACTIVE 唯一、邀请/岗位/到期
- `project_code`：code_hash 唯一、code_ciphertext/key_id、每项目唯一 ACTIVE

## 4. 实现要点

### 4.1 项目创建

- 当前学生必须为 STUDENT 且具备课程资格（有效核验选课或课程成员）。
- 作业必须属于请求的广场；capacity 必须落在作业 min/max。
- 创建者同事务写入 project、默认阶段“默认阶段”、leader membership、assignment_team_slot；`(assignment,user)` 唯一约束是最终防线。
- DETAILED：roles 非空、岗位总人数=capacity、leaderRoleKey 必须指向本次岗位（clientKey 或 roleName）；QUICK 可省略名称/岗位。
- 项目组队码在创建时生成，只存 SHA-256 + AES-GCM 密文。
- 所有写接口接入幂等；创建失败回滚项目/岗位/成员/资格/码。

### 4.2 申请与邀请

- 申请只 PENDING，不占正式关系；DETAILED 必须 roleSlotId 且岗位有余量，QUICK 不接受 roleSlotId。
- 申请/邀请都要求项目 ACTIVE、招募开放、有剩余容量、非同作业已有资格、无 PENDING 申请/邀请。
- 申请 APPROVE 后原子创建 PENDING invitation（24h）和 ACTIVE seat_reservation；不直接成为成员。
- 本人 ACCEPT 才创建 membership 与 assignment_team_slot；锁 project、检查邀请有效期/容量/岗位/已有资格，消耗预留，关闭同作业其他 PENDING 申请/邀请，刷新项目 revision。
- DECLINE 必须理由；REVOKE 必须理由；均释放/关闭预留。
- 邀请过期在请求时检查并拒绝，不等待后台任务。

### 4.3 招募、组队码与总览

- TEAM-01 返回完整招募项目，过滤非 ACTIVE/未开放/满员，支持 role/mode/professionalDirection/q。
- TEAM-10 邀请候选固定最多 20 条，来源 APPLICATION/COURSE，q 1～80，绑定 expectedProjectRevision。
- TEAM-11 组队码由 LEADER 或当前成员查看；TEAM-22 ENABLE/DISABLE/ROTATE 仅 LEADER，核对项目 revision。
- TEAM-19 只解析 ACTIVE 组队码，返回 ProjectView 与当前 canApply；不写成员关系。
- TEAM-25 Dashboard 从本人 PENDING 邀请/申请和 ACTIVE 项目派生计数；TEAM-26 Todo 只返回 ACTION/WAITING 的真实状态项，不把清提示当办理。
- TEAM-06 当前返回真实空集：作品来源证据属于 P11，P03 尚无已验收交付。

1. **TEAM-06 工作来源**：P11 作品证据尚未实现，当前返回真实空列表；不伪造交付/贡献数量。
2. **Dashboard/Todo**：当前只派生邀请与申请；任务、约定、验收、人员事项等后续模块接入后扩充。
3. **项目归档/收尾**：`CLOSING/ARCHIVED` 仅在枚举，P10 才实现；P03 不提供归档动作。
4. **岗位修改**：PATCH 项目时 DETAILED capacity 必须等于当前岗位总和；完整换岗/协商属于 P04。

6. **组队码**：项目创建时生成，只存摘要+密文；ENABLE 对已 DISABLED 的最新码重新启用，ROTATE 会撤销旧码。
7. 项目/招募/成员列表当前完整返回，不做分页快照；后续若数据量需要再按 §3.4 接入游标。
