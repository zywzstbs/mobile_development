# P10 报告与归档

阶段状态：**已完成并通过真实 PostgreSQL 集成验证**。本阶段按用户要求停在 P10，P11 尚未开始。

## 1. 交付范围

- 实现 REPORT-01～12：报告读取/快照、交付草稿/预览/发布、个人与整体复盘、收尾/恢复/归档。
- 新增 `V013__reporting_and_archive.sql`，持久化个人复盘、整体复盘、交付草稿、10 分钟预览凭证、不可变交付版本和报告快照；项目增加 `archived_at`。
- 报告固定为 overview、divisionAndProcess、deliveriesAndAcceptance、memberWork、retrospective 五栏。成员投影包含当前成员与确有任务、份额、提交或贡献记录的历史参与者，不输出成绩和原始互评。
- 预览令牌仅存摘要；发布时重验来源摘要、草稿版本、发布者、有效期与一次性使用状态。报告快照按来源摘要和收尾轮次保持不可变。
- 收尾时关闭招募，取消待处理邀请、申请、席位预留并撤销项目码；已有任务可以继续。恢复活动后再次收尾会增加 `closingCycle`。
- 归档检查未完成任务、待验收提交、未确认贡献、未结正式约定/提案/人员变更、交接重签和验收人邀请。非空项目必须绑定当前交付与本轮 FINAL；EMPTY 只允许无任务、正式约定或提交历史的项目。ARCHIVED 不可恢复，组内写入只读。

## 3. 验收用例

`ReportP10IT` 已编译，包含：

1. 预览后来源变化拒绝旧令牌；发布与复盘生成报告；来源变化后旧 FINAL 不能归档；刷新当前交付和 FINAL 后归档；归档后快照可读、写入拒绝。
2. 真实空项目可用 EMPTY 快照归档，不需要交付发布，且不能恢复。
3. 有任务历史的项目不能伪装成 EMPTY。
4. 恢复 ACTIVE 后再次进入 CLOSING 会增加收尾轮次。
5. 已验收但未本人确认的正式贡献阻止归档，并保留报告的正式分项与验收投影。
