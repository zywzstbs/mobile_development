## 3. 实现要点

- 作品来源项目必须是本人实际合作项目；作品保留不可变 `work_version` 历史，撤回后不可重新提交，只能保留历史。
- 作品可见范围与来源授权取交集：PRIVATE 仅作者；TEAM 需共享来源项目成员关系；CLASS 还需同校课程资格/成员关系。非作者读取不返回版本历史。
- 互评仅项目实际成员、不能自评、每项目/作者/对象唯一；项目归档后才进入互评，窗口为归档后 14 天。
- 原始互评只允许作者读取；被评者和其他成员不能读取原文。撤回保留历史，状态变 WITHDRAWN。
- 作品/互评均使用真实版本号；写接口接幂等，回放不重复写版本。
- AI 参考仅组长发布，`origin=CLIENT_BYOK_LEADER_CONFIRMED`，`sourceProjectId` 必须等于当前项目，`clientRecordId` 每项目唯一；同记录不同正文 409；拒绝 API 密钥样式 model、跨项目来源和超长文本。
- AI 参考正文最多 16000 字符；客户端 AI 不被宣称为服务器生成证明，不自动派任务或改分。

1. **匿名合作汇总**：已按三维分别统计有效作者，只有单维达到 3 位不同作者才返回 `VISIBLE` 汇总；当前演示数据不足 3 位作者时保持空集和不可见，不对少样本泄露。本人显式同意字段尚未单独持久化，当前以匿名阈值作为展示门槛。
2. **教师文字评价**：`teacherSummaryStatus=NOT_AVAILABLE`、`teacherSummaries=[]`；教师评语/授权属于 P09/P10 后续接入，未伪造。
3. **作品材料**：当前只接受 `LINK`；`FILE` 需接入 P05F 的 READY/授权校验后再开放。
4. **互评窗口**：只对已归档项目开放；P10 已提供 `archived_at`。归档/恢复与 14 天边界由请求时判断，定期任务归 P16。
5. 画像 `processSummary` 当前为空对象；不输出原始互评、成绩或组内限制材料。
6. 未做 Android 联调、云部署。
