## 3. 数据库迁移 V004

新增：

- `teacher_assignment`：每广场最多一名 ACTIVE 教师；V004 为已有真实广场回填当前教师
- `teacher_claim`：同广场/同人 PENDING 唯一；PENDING/APPROVED/REJECTED/CANCELLED
- `teacher_transfer`：每广场最多一个 PENDING；记录 source_revision
- `class_grant`：square+user 唯一；能力白名单、状态、expires_at、granted_by
- `course_code`：`code_hash` 唯一；`code_ciphertext`/`key_id`；每广场最多一个 ACTIVE；code_version
- `course_join_request`：同广场/同人 PENDING 唯一；PENDING/APPROVED/REJECTED/WITHDRAWN
- `cursor_snapshot`：15 分钟分页 ID 快照、位置、query_hash、epoch

课程码只存摘要 + AES-GCM 密文；`GET current` 才能取回当前明文码。

## 4. 实现要点

### 4.1 教师权属与认领

- 当前教师来自 `teacher_assignment`，不再以 `verified_course.teacher_user_id` 直接授权；该字段仍是核验事实。
- 广场创建关联真实教学班时，服务器建立当前教师 assignment。
- TEACH-07 只创建 PENDING 认领，不自动授权；已核验广场只允许核验名单指定教师认领；普通教师只能在无当前教师的广场申请。
- CLI `review-teacher-claim` 由管理员显式 APPROVE/REJECT；APPROVE 才建立 teacher_assignment 并刷新 square revision/authorization_epoch。
- 学生/普通用户不能自授教师；已有当前教师时不能重复认领。

### 4.2 班级授权

- 仅当前教师可授予/撤销；能力白名单不含改分、验收：ANNOUNCEMENT_WRITE、PERSONNEL_READ、PERSONNEL_HANDLE、TEAM_SUMMARY_READ、MATERIAL_REQUEST_HANDLE、COURSE_JOIN_CODE_MANAGE、COURSE_MEMBERSHIP_REVIEW。
- expiresAt 默认学期末 23:59:59（学校时区）；请求不接受任意过期字段。
- 被授权人必须是同校且本课程有效成员（核验选课或 ACTIVE membership）。
- 授权/撤销刷新 square revision 和 authorization_epoch。
- TEACH-01 只返回本人当前 ACTIVE grant 的班级；教师工作台在 TEACH-02。

### 4.3 课程码与入课

- TEACH/助理 `COURSE_JOIN_CODE_MANAGE` 可签发，expectedRevision 核对 square；默认 86400 秒（300～86400）。
- 每课程最多一个 ACTIVE 码；新码原子撤销旧码；转交接受、撤销均使旧码失效。
- COURSE-16 只解析和核验，不写成员关系；返回 membershipStatus、verificationStatus、canConfirm、existingRequestId 和 5 分钟 confirmationToken。
- 可信名单确认（COURSE-17）重新核对 token、用户、课程码 revision、选课事实 revision，事务内建立唯一 ACTIVE membership；已 ACTIVE 直接返回原关系。
- 无可信事实时走 COURSE-18 申请：无当前合法审核者（T 或 REVIEW 助理，排除本人）返回 503，不建假单；已有 PENDING 返回原单。
- COURSE-20/21/22：当前教师或本班 REVIEW 助理读取/决定；本人不得自审；APPROVE 必须有有效核验选课事实并原子建立 membership；REJECT 保留理由，membership=null。
- COURSE-19/20 使用 15 分钟 ID 快照游标；授权 epoch 变化使审核队列旧游标失效。

### 4.4 退出与转交

- TEACH-08 当前教师退出前必须无 ACTIVE 班级授权、无 PENDING 转交；退出结束 assignment 并刷新 revision/epoch。
- TEACH-09 指定同校已核验 TEACHER，创建 PENDING transfer，固定 source_revision；未接受前原教师权属不变。
- TEACH-10 仅接任教师本人回应；ACCEPT 重新锁 square 并核对 source_revision、源教师当前 ACTIVE，接受后结束源 assignment、建立新 assignment、撤销全部旧课程码、刷新 revision/epoch；DECLINE 必填理由。
- 转交/授权/课程码写入均先锁 square，避免旧教师并发写入。
