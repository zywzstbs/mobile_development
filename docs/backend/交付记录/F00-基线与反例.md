## 4. 测试基础设施边界

- `target/run-pg.sh` 每次新建/复用**一次性**集群；测试结束立即 `pg_ctl -m immediate stop`。
- 迁移升级测试使用独立 schema（`gulupai_p16_empty/restore`、`gulupai_chat_v18_upgrade`），不触碰开发数据。
- 并发用例使用两个真实 HTTP 请求线程 + 栅栏，不用串行调用冒充并发；同一客户端标识的发送依赖 `chat_counter` 行锁和唯一约束。
- 时间边界使用 `MutableClock`，不 sleep。
- 本轮没有 Android 客户端运行环境，因此不将任何接口标为“Android 联调通过”。
