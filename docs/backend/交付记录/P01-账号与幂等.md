## 3. 数据库迁移 V002

新增表：

- `school`：P01 账号归属所需最小学校维度（P02 继续 term/period/verified_course）
- `app_user`：`login_id` 全局唯一；`school_id+student_no` 部分唯一；身份状态 CHECK；`skills_json`
- `user_role`：联合主键，只允许 `STUDENT/TEACHER/CLASS_ADMIN`
- `user_profile`：`intro`、`profile_json`、`visibility_json`、revision；首次更新前无行，GET 返回 revision 0
- `auth_session`：`refresh_hash` 唯一，`expires_at` 固定 7 天，`revoked_at`
- `access_token`：`token_hash` 唯一，`expires_at` 30 分钟，`revoked_at`
- `operation_receipt`：`(user_id, method, path, key)` 唯一；加密结果、key_id、resource_refs、7 天到期
- `audit_event`：动作/资源/前后版本/requestId；不存密码、令牌、正文
- `rate_window`：`(subject_hash, rule, window_start)` 唯一；固定窗口计数与 blocked_until
- `import_batch`：文件摘要、导入者、状态、汇总

关键约束名：`uq_app_user_login`、`uq_app_user_school_student_no`、`uq_auth_session_refresh_hash`、`uq_access_token_hash`、`uq_operation_receipt_scope`、`uq_rate_window_scope`。

## 4. 安全与幂等实现要点

- 令牌：SecureRandom 32 字节、base64url；数据库只存 SHA-256 摘要；access 1800 秒、refresh 固定 7 天。
- 刷新：事务内 `auth_session ... FOR UPDATE`，检查 revoked/expires，签新 access，不更新 session 到期时间。
- 注销：锁会话、撤销会话及该会话全部 access；同一幂等键重放返回 `revoked=true`；其他设备不受影响。
- 认证过滤器：逐请求联查 access/session/user，检查到期、撤销、停用；用户停用即时 401；注销后的旧 access 仅允许“同路径注销重放”受限主体。
- 登录限流：按 loginId 摘要 + 来源 IP 固定窗口；第 5 次失败封 15 分钟；429 带 `Retry-After`；成功清理失败计数。
- 登录时序：未知账号执行一次同等成本假哈希校验；失败统一 `INVALID_CREDENTIALS`；停用账号在正确口令后返回 `ACCOUNT_DISABLED`。
- 幂等：键 1～128 可打印 ASCII；作用域 `(userId, method, path, key)`；规范 JSON 对象键递归排序、数组顺序与字符串原值保留；`pg_try_advisory_xact_lock` 拿不到返回 409 `OPERATION_IN_PROGRESS`；同键异正文 409 `IDEMPOTENCY_KEY_REUSED`；结果 AES-256-GCM 加密并记录 key_id；回放前重新核验当前登录/停用状态。
- 首次画像/可见性 expectedRevision=0；更新使用 `UPDATE ... WHERE revision=?` 语义（行锁后核对），冲突 409 `RESOURCE_CHANGED`。
- 口令：1～256 字符不 trim；先 SHA-256 再 Spring BCrypt(cost 10)，避免 BCrypt 72 字节静默截断；数据库只存 BCrypt 结果。

`AuthP01IT` 覆盖：

- 登录成功：Session 字段、`capabilities=[]`、密码/refresh/access 均无明文入库、默认 deviceLabel
- 错误口令与未知账号统一 401，不泄露账号存在性
- 5 次失败后第 6 次 429 且带 `Retry-After`；16 分钟后恢复
- access 30 分钟到期；refresh 可续 access 但 `refreshExpiresAt` 不变
- refresh 固定 7 天到期后拒绝
- 注销撤销当前会话全部 access、其他设备仍可用、同键重放 `revoked=true`
- 注销缺少幂等键 400 且不产生半成品
- 用户停用后旧 access 立即 401、登录 403 `ACCOUNT_DISABLED`、refresh 401
- 画像首次 revision=0、首次更新 expectedRevision=0、同键重放不重复递增、同键异正文 409、旧 revision 409
- 可见范围默认值与 revision 流程
- 并发同键画像更新：一次业务效果、一条回执、profile revision=1
- 并发 refresh/logout：会话行序列化，最终全部 access 撤销，无 500
- 数据库异常中途回滚：无回执、无审计残留
- 登录请求自授 `capabilities` 被 422 拒绝
- 公共帮助读取路径不被强制 401

## 7. 已知边界与遗留

1. 公共帮助读取路径白名单已预留，但 HELP-01～03 控制器属于 P15；当前请求返回 404，不是假成功。
2. `capabilities` 当前固定为 `[]`；P15 接入真实 `operator_grant` 后才派生 `HELP_CONTENT_WRITE`，不接受客户端自授。
3. 幂等回执与登录失败窗口的定期清理任务尚未接入；当前由 `expires_at`/`window_start` 保留，P16 统一清理。
4. 注销后访问令牌行保留 `revoked_at` 以供审计/排查；P16 清理策略统一处理。
5. `X-Forwarded-For` 未被无条件信任；代理来源处理需部署阶段按受控反代配置。
6. 未实现 Android 联调，未部署云服务器；当前验证是本机真实 PostgreSQL + HTTP。
7. 剩余 273 个接口、文件数据面（P05F）、帮助/求助/举报（P15）未开始。
