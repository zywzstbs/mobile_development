## 4. 实际验证结果

环境：Temurin Java 21.0.13、Maven 3.9.11、Spring Boot 3.5.16、PostgreSQL 17.11、Flyway 11.7.2。

### 4.1 单元与 MVC 契约测试

命令：

```bash
./mvnw test
```

实际结果：`Tests run: 24, Failures: 0, Errors: 0, Skipped: 0`，BUILD SUCCESS。

覆盖：

- 成功信封 `code=OK,message=成功`，创建也返回 HTTP 200；
- UTC 秒级时间 `2026-10-31T06:15:11Z`，去掉输入小数秒；
- 点数字符串输出规范化 `12.3 → 12.30`，不变成 JSON number；
- 未知字段 422 `FIELD_NOT_ALLOWED`；类型不匹配 422 `VALIDATION_FAILED`；字符串/小数/布尔到整数均拒绝；
- 空正文/畸形 JSON 400 `MALFORMED_JSON`；
- 未认证 401 `SESSION_EXPIRED`；未知路由（已认证）404 `NOT_FOUND`；方法不支持 405；
- 中文与 emoji 代理对的 UTF-16 边界（5 单元通过、6 单元拒绝）；
- Decimal 拒绝 `1.234/01/1e2/-1/1000000.01/.5/1.`，接受 `0/999999.99/1000000/12.3`；
- JSON 正文 >1MiB → 413 `PAYLOAD_TOO_LARGE`；
- 响应 >2MiB → 413 `PAYLOAD_TOO_LARGE`；完整集合 >1.75MiB → 413 `COLLECTION_TOO_LARGE`；
- 未处理异常 500 `SERVER_ERROR`，不泄露堆栈。
