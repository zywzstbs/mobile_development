## G02 / S02 正式贡献绑定提交版本

改动：

- 重写 `WorkSourceQueryService`：单一证据 CTE，`sources` 与 `canReference` 共用。
- 正式交付：`unit_share.agreement_version = submission.agreement_version`，且 unit 在 `submission.unit_ids_json`，`submission.status='REVIEWED'`、`ua.passed=true`、acceptance 属于同一 submission。
- 确认项：`contribution_confirmation` 同时关联 acceptance/submission，并要求本人份额属于该提交版本。
- 独立验收：按 acceptance.id 去重；自验排除只检查该 submission 当次版本的贡献者，旧版本份额不永久排除。

- 历史完成项按当时提交版本保留；A 的 v1 未完成责任不分享 B 的 v2 成果。

改动：

- `V020` 新增 `personnel_case_grant`（case/user/status/revision/granted_by/granted_at/revoked_*/reason/expires_at），有效授权唯一索引。
