## 3. 实现要点

- 普通任务必须有 `dueAt` 和至少一条标准，负责人为空，状态 `TODO`。项目锁内最多 200 个任务。
- 认领只针对无主普通 `TODO`。`startNow` 省略为 false，保持 `TODO`；为 true 时同时开始。`BEFORE_START` 在认领和开始时都要求前置任务已 `DONE`。`BEFORE_SUBMIT` 不阻挡认领。
- 开始只允许当前负责人。移动阶段只改 `stageId`，不改状态。
- 阶段：非空 id 定位已有行，空 id 或省略 id 为新增，可选 `clientKey`。使用 `order` 时必须是 0～n-1 的连续整数并按它排序；都不传则按数组顺序。名称规范化后不能重复，最多 12 个。不能删除仍被任务引用的阶段，也不能用陌生 id 当新增。
- 依赖必须属于同一项目，不能自依赖、重复或成环。任务开始后不能再新增 `BEFORE_START`。
- 颜色只改本人，固定 8 色，按大写比较。首次颜色版本是 0。
