# P16 第五步：演示种子与单机编排

日期：2026-11-01  
状态：本步完成。没有构建镜像，也没有上云。当前机器没有 Docker，Compose 文件未实际启动。

## 演示种子

```
java -jar app.jar --spring.profiles.active=cli --app.cli.command=demo-seed \
  --app.cli.scenario=full --app.cli.dry-run=true

java -jar app.jar --spring.profiles.active=cli --app.cli.command=demo-seed \
  --app.cli.scenario=full --app.cli.credentials-file=/受控路径/demo-credentials.txt
```

`full` 写入 1 所学校、1 个学期、2 个真实教学班。每班 1 名教师、1 名助理、8 名学生，另有 1 名独立受理账号。移动班有两个历史广场，数据库班有一个广场，用来区分合并和跨班拒绝。受理账号获得全局 `HELP_ADMIN`、`HELP_CONTENT_WRITE`、`SUPPORT_HANDLE`、`CONTENT_REVIEW`。帮助文章随种子导入。

口令随机生成，只写入调用方指定的文件，权限为所有者读写。命令摘要不包含口令。再次执行会沿用原口令，不会多出广场或账号。

这批数据是名册、选课和历史广场，还没有组队、任务、成绩、聊天这些现场操作对象。

## 编排

`deploy/compose.yml` 有 proxy、app、db。只映射 80/443。数据库口令通过环境变量传入，示例在 `deploy/.env.example`。内存上限按设计取 app 800MiB、数据库 450MiB、代理 96MiB。应用堆为 `-Xms128m -Xmx448m`，连接池 6，Tomcat 线程 24。镜像标签已固定为 `postgres:17.6`、`caddy:2.10.2`、`eclipse-temurin:21-jre-jammy`，digest 尚未锁定。

生产环境若设置固定时钟，启动直接失败。演示环境仍允许固定时钟。

TEST_DB_URL='jdbc:postgresql://localhost:55432/postgres?currentSchema=gulupai_test' \
  ./mvnw -Dit.test=DemoSeedIT verify
