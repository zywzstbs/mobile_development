## 3. 实现要点

- 通用帮助匿名可读；课程帮助要求当前课程资格；文章反馈唯一 upsert；运营改文章需 `HELP_ADMIN`。
- 支持路由白名单由 `support_route` 控制；无可用路由/无处理人返回 503，不生成假单号。
- 工单 `clientRequestId` 本人唯一；创建保存路由与正文；接受使用条件更新竞争唯一负责人。
- 处理人状态 IN_PROGRESS/WAITING_USER/ANSWERED；处理人回复才 ANSWERED；本人 `resolved=true` 关闭并记录 resolvedBy，处理人关闭不冒充本人解决。
- 关闭后 7 天内本人可重开；转交目标必须当前有 `SUPPORT_HANDLE`，失败保留原负责人。
- 举报只核本人当前可读的主题/回复/聊天；selectedExcerpt 必须来自当前正文，保存来源版本与最少片段，不复制全群。
- 举报处理需 `CONTENT_REVIEW`；ACCEPT/RECORD_RESULT/CLOSE 只追加处理记录，不自动删文、移人、扣分。
