# P16 第四步：帮助导入与运营授权

日期：2026-11-01  
状态：本步完成。没有新增 HTTP 自授接口。

## 命令

```
java -jar app.jar --spring.profiles.active=cli --app.cli.command=help-import \
  --app.cli.file=admin/fixtures/p16-help.json --app.cli.dry-run=true

java -jar app.jar --spring.profiles.active=cli --app.cli.command=operator-grant \
  --app.cli.user-id=<用户编号> --app.cli.capability=HELP_CONTENT_WRITE \
  --app.cli.scope-type=GLOBAL --app.cli.active=true
```

能力只允许 `HELP_ADMIN`、`HELP_CONTENT_WRITE`、`SUPPORT_HANDLE`、`CONTENT_REVIEW`。范围是 `GLOBAL` 或已存在的 `SQUARE`。

## 行为

- 帮助文件先整份校验。版本必须是三段数字或 `MAJOR.MINOR.*`。通用文章不能绑广场，课程文章必须指向现有广场。dry-run 不写库；内容不变不增加 revision。
- `/me` 只在存在有效的全局 `HELP_CONTENT_WRITE` 时返回该能力。广场范围授权不升成全局提示。撤销后能力数组为空。
- 改帮助文章仍要 `HELP_ADMIN`。没有该授权时接口返回 403。
