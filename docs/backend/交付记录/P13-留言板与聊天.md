## 3. 实现要点

### 留言板

- 主题列表只返回项目成员可见内容，置顶优先、再按活动时间；支持 status/q。
- 主题/回复创建与修订都核项目可写状态；归档只读。
- 回复必须同主题且父回复为根回复，限制一层。
- 新增回复只增加 reply_count/activity，不增加主题 revision；并发回复不产生伪版本冲突。
- 作者可修订/撤回；撤回清正文、refs、mentions，保留占位；历史 revision 正文同步清空。
- RESOLVE/SET_HELPFUL 仅作者；CLOSE/置顶仅组长；RESOLVED 作者可重开、CLOSED 组长可重开；置顶最多 3 个。
- 关注仅本人；关注不改变主题正文 revision。

### 聊天

- 消息序号由 `chat_counter` 原子分配，消息与序号同事务。
- `(project, author, clientMessageId)` 唯一；同 ID 同正文返回原消息，异正文 409。
- 内容与 refs 至少一项；refs 最多 5 且当前仅接受本项目的 TASK 引用；mentions 最多 20 且必须当前成员。
- 撤回仅作者、项目可写、发送后 120 秒内；保留 sequence，清正文/refs/mentions，revision+1，并写 changeSequence。
- 变更流独立 sequence；`afterChangeCursor` 返回后续变更，撤回会出现在 changes 中。
- 阅读游标只存本人、单调 max、不能超过 latestSequence；不伪装他人已读。
- 写通知 outbox：CHAT_MESSAGE_SENT / CHAT_MESSAGE_WITHDRAWN，P14 再投影。
