## 3. 实现要点

- 普通任务不进入账本。责任 30.00、验收 20.00 时履约分为 67。权重 0.60、成果分 80、调整 2 时课程分为 74。权重乘法的中间结果不提前舍成整数。
- 未签、已验收但未本人确认、截止前未完成，都会挡住结算。截止后仍未完成时，责任保留，验收按 0。责任合计为 0 不能结算。
- 教学更正写入绝对点数，不改组内原始份额。迟交通过后旧结算的来源不再匹配，必须重结算再发布；旧快照保持原值。
- 发布前固定整批学生和每人的依据摘要。任一人变化则整批 `PREVIEW_STALE`，不写出新快照。分数相同但依据变了，可以发新版本。没有实质变化不增加版本。
- 教师决定修订后，状态停在等待新成绩。发布时带上这条复核和新快照，才成为 `RESOLVED_REVISED`。
- 文字评价引用正式成绩。学生的展示授权只对应当时的内容版本，改写后旧授权不沿用。撤回评价不改已发布成绩。撤掉教师身份后不能发布。
