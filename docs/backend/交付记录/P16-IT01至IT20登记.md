## 本步补上的缺口

- IT01 账号切换：`AuthP01IT.accountSwitchDoesNotReplayThePreviousUsersLatePacket`。同一幂等键在两个账号上各自生效，资料不串号；注销后旧 token 重放返回 `SESSION_EXPIRED`。
- IT04 同作业两队同时接受：`TeamP03IT.concurrentAcceptOfTwoTeamsKeepsOneAssignmentMembership`。只留下一条 `assignment_team_slot`、一条有效成员，失败一侧没有残留有效预留。
- IT04 末位席位并发：`TeamP03IT.concurrentApprovalForLastSeatCreatesOnlyOneReservation`。
