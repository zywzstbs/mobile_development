## 状态和维护规则

- 需求以最新明确变更为准；实际完成状态以代码及相应版本的测试/审查证据为准。修复方案不等于修复已经实施。
- `P00～P16` 是后端实施阶段，`P50/P58/P62/P66` 是客户端及契约演进编号；制品版本 `0.1.0-P16` 不表示未做 P66。
- 新增审查/回告放在对应版本目录，写明日期、基线、测试命令、失败/跳过及未完成项，再更新入口。
- 历史记录保留原路径，避免破坏文内链接；旧结论加时间和范围说明，不把旧验收结果改写成当前通过。
- 合并交接中的“当前工作区仅有客户端”等是原交接方视角，不是本后端仓库现状。
