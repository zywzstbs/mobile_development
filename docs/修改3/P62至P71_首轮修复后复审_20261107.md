## 2. 新增测试的有效性

- `PlatformCursorExpiryP66IT` 用 MutableClock 和真实 cursor_snapshot 验证多次续页期限相等、原期限恰好到期时全部旧游标失效、新首页创建新快照，以及末页不产生多余快照。测试时 accessToken 尚有效，断言确实落在游标期限上。
- `PlatformReadPrivacyP66IT` 修正了原来只插 ACTIVE 授权头的正向夹具，改为完整授权。反例覆盖缺角色、当前授权缺能力或范围、历史授权元数据不能补当前授权、身份/资格/凭据异常、真实停用、撤销历史及规模上限。
- `NoticeOutboxSourceVersionTest` 的 36 项用例检查真实 worker 的类型转换与 JDBC 调用，包含小数、溢出、非正值、非数值及载荷结构异常。
- `NoticeOutboxSourceVersionIT` 使用真实 PostgreSQL 和 Spring worker Bean 验证聊天生产者冻结版本、两名接收人、坏事件保持待处理、消息撤回后仍保存原事件版本、公告版本以及重试去重。
- 事务反例通过触发器让第二个接收人 INSERT 失败，再查事务结束后的数据库，确认前一事件和已插入通知一起回滚。解除注入后重试成功。
- 已读动作与随后 drain 的独立事务也有专门验证，drain 返回 5xx 时前面的已读动作可能已经提交。文档正确登记了这一事实。
