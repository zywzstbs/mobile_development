## 4. 上线与恢复

本记录不是上线授权。若以后另行批准：

1. 在隔离库用最终 `V031` 从现有 `V030` 升级，并核对历史停用账号没有被激活。
2. 用 `init-super-admin` 指定一个已经激活、已核验的独立账号。口令不进入文档、命令历史或日志。
3. 先只开放读取。写入等客户端按联合契约发送绑定并校验回执后再开放。
4. 恢复仍保留原 CLI。不要删除 `platform_admin_lock` 这一行。至少保留一位可登录、授权有效且具备账号管理与超管管理能力的管理员。
